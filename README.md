# FeedCare AI — SIH Prototype v2

## New features
- Early-warning feed/silage use-by reminders based on prototype sample/storage logic.
- Browser notification permission for reminder alerts.
- Feed quality history with nutrient trend comparison over saved tests.
- Personalized feed advisory using animal profile.
- Pregnancy-aware general nutrition guidance; advises discussion with a qualified livestock nutritionist.
- Voice commands using the browser Speech Recognition API.
- Voice playback for advisory text.
- Camera capture for feed/silage samples.
- Back-of-packet nutrition-facts photo module with clearly labelled demo OCR inputs.
- Unique farmer QR identity card containing a demo farmer ID and cattle counts.
- QR is generated by the included local Python server.

## Run
1. Install Python 3.
2. Install QR dependencies once: `pip install qrcode pillow`
3. Double-click `START_FEEDCARE.bat`.
4. Open `http://localhost:8000` if it does not open automatically.
5. Demo OTP: `123456`.

## Important
All AI values, OCR values, demo sensor values and prototype analytics are explicitly advisory/simulated. They are not certified laboratory measurements. Pregnancy guidance is general and should not be used as a replacement for professional ration formulation.
